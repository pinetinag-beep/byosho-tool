# 診療科ごとの特徴を示す施設基準の届出

全国の施設基準の届出（地方厚生局の名簿、2026年11月までの公表分）から、診療科ごとに、その診療科で主に行う手術・検査・治療・入院管理の届出を**MedilenZが選んで分けた**一覧です。公式の「診療科別の届出一覧」はありません。

- 1つの届出が複数の診療科に入ることがあります（例：経カテーテル弁置換術は循環器内科と心臓血管外科）。
- ほとんどの医療機関が届け出ていて特徴にならない届出（感染対策・ベースアップ評価料など）は入れていません。
- 届出が要らない手術・治療（ふつうのPCI・胃のESD・ステントグラフトなど）は名簿に載らないため、ここにもありません。
- 届出があっても、診療の量（件数）は分かりません。
- 件数は、その届出をしている全国の医療機関の数です。
- 定義（検索に使う形）は `kijun_web/specialties.py`。
