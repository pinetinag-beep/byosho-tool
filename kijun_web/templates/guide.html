施設基準とは？ 届出の調べ方とこのサイトの使い方

施設基準とは

保険診療の報酬（診療報酬）の中には、人員の配置や設備、診療の体制などが一定の基準を満たしている医療機関だけが算定できるものがあります。 この基準を「施設基準」といい、医療機関は基準を満たしていることを地方厚生局（または都府県事務所）に届け出て、受理されてから算定を始めます。

たとえば次のようなものがあります。

  • 入院基本料：急性期一般入院料、療養病棟入院料など。看護職員の配置などで区分（急性期一般入院料１〜６など）が分かれます。
  • 特定入院料：地域包括ケア病棟入院料、回復期リハビリテーション病棟入院料、緩和ケア病棟入院料、特定集中治療室管理料など。病棟や治療室の機能を表します。
  • 加算・指導管理料など：入退院支援加算、認知症ケア加算、がん患者指導管理料、在宅療養支援診療所など。

どの施設基準を届け出ているかを見ると、その医療機関がどんな病棟を持ち、どんな診療や体制に力を入れているかのおおよそが分かります。

届出の状況はどこで公表されているか

各地方厚生局は、受理した届出を「施設基準の届出受理状況（届出受理医療機関名簿）」として、都道府県ごとにExcelやPDFで公表しています。 ただし厚生局ごとにページやファイルの形式が違い、全国をまとめて調べるのは手間がかかります。

MedilenZではこれを全国47都道府県分まとめ、毎月1回を目安に最新の公表分に更新しています。収録している医療機関は {{ "{:,}".format(meta.n_facilities|int) }} 件、 届出は {{ "{:,}".format(meta.n_filings|int) }} 件、施設基準は {{ "{:,}".format(meta.n_kijun|int) }} 種類です（{{ meta.as_of_max_label }}までの公表分）。

受理記号と区分

  • 受理記号：届出名称の略称です（例：「地包ケア１」＝地域包括ケア病棟入院料１）。トップの「届出項目」には受理記号が並んでいて、「正式名称で表示」で正式名称に切り替えられます。
  • 区分：入院基本料などは、同じ届出の中で区分（急性期一般入院料１など）が分かれます。区分を公表していない厚生局（北海道など）の届出は、厚生労働省「病床機能報告」から補った値を参考として別に表示しています。

このサイトの使い方

1. 条件で医療機関のリストを作る

トップの表で、都道府県（複数可）・二次医療圏・市区町村・施設の種類を選び、「届出項目」で受理記号にチェックを入れて「リストを抽出する」を押します。 届出項目を複数選んだ時は「すべてを届け出ている」「いずれかを届け出ている」を選べます。結果はCSVでダウンロードでき、選んだ届出項目ごとに届け出ているかどうか（○）の列が付きます。

2. 医療機関を調べる

トップの「医療機関名・住所」に名前の一部を入れると候補が出ます。選ぶと、その医療機関が届け出ている施設基準の一覧（受理番号・算定開始日・区分など）が開きます。

3. 施設基準ごとに地域で比べる

施設基準の一覧から施設基準を選ぶと、都道府県ごとの届出医療機関数と、病院・診療所の内訳が見られます。都道府県を押すと、その県の医療機関の一覧になります。

使うときの注意

  • 公表データは、届出の受理から公表まで時間がかかることがあり、最新の状況と異なる場合があります。
  • 本サイトのデータは公表データをMedilenZが編集・加工したものです。正確な情報は各地方厚生局の公表資料、または各医療機関にご確認ください。
