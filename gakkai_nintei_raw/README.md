# 学会認定施設データ（生ファイル置き場）

各学会が公表している「認定施設一覧」（専門医研修施設・認定施設等）の生データを
学会ごとに置いていくフォルダ。詳細は CLAUDE.md の「学会認定施設データ」セクションを参照。

## 運用ルール

- ファイル名は `<学会名>_<形式が分かる補足>.拡張子` を推奨（例: `日本外科学会_専門医修練施設.xlsx`）
- Excel/PDF/CSV等、学会ごとに形式が異なる前提。まず1学会分のサンプルを確認してから
  パーサーを作る（施設基準届出データで学会ごと・厚生局ごとに形式が違って苦労した教訓を踏まえる）
- 処理済みデータは `gakkai_nintei_cache.parquet`（未作成）にまとめる予定
